# Overview

This page shows how to handle product updates.

# Instructions

## Full

1. Launch VS Code on the machine where you are aiming to update our extension.
2. Select the "Extensions" icon in the VS Code activity bar (left of screen).
3. Scroll on the sidebar that appears (if needed) and click on the "gear" icon
4. On the menu that pops up, select "uninstall".
5. You will see a button appear on the extension's area in the sidebar that says "Restart Required". Click it.
6. Although it seems like that is enough, you will have to completely quit VS Code so that the old variant is not cached. 
7. From there, you must proceed through the same steps as listed in the [QuickStart](https://cse110-sp26-group02.github.io/cse110-sp26-project-site/quickstart/).

## Simplified

1. Follow the steps on the [De-Installation](https://cse110-sp26-group02.github.io/cse110-sp26-project-site/management/de-installation/) page.
2. Follow the steps on the [QuickStart](https://cse110-sp26-group02.github.io/cse110-sp26-project-site/quickstart/) page.
