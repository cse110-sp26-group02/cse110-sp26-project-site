# Overview

This page outlines the requirements/restrictions imposed on the user if they want to use the product.

# List

## Local

* **OS**: any macOS, Windows, or Linux variations that support VS Code 1.119+
* **VS Code Versions**: 1.119-1.120 confirmed; 1.120+ likely ([install from https://code.visualstudio.com/download](https://code.visualstudio.com/download))

## Cloud Providers

### Options

* **Cloud Storage Provider for Repo Storage/Management**: [GitHub](https://github.com/) (must have an account; can be free)
* **Cloud Model Provider for Tracking**: Google (must have an account; must also register for [Google AI Studio](https://aistudio.google.com/welcome)); can be free)

### Cost

* **Minimum Payment for Google Gemini Model**: $0.00

### Authentication

* **GitHub Authentication**: fine-grained PAT
* **Google AI Studio Authentication**: API key (must have Google account; can be free)
