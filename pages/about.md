# Overview

This page overviews the origin and philosophy of the project. 

# Origin

The product and this manual was created by 11 students in CSE 110 at UC San Diego for the Spring 2026 quarter. It introduces one of the first pure agentic Issue "trackers" as an IDE extension.

# Mission

To provide an affordable Agentic Issue Tracker (AIT) available as a VS Code extension for GitHub issues that is highly auditable through live generative LLM agent detection, step-tracing, and cost-tracking, is interpretable through well-curated statistical figures, is efficient due to smart REST API calls, is time-saving through generative summaries and judgement of Issues, is learnable due to seamless integration into the IDE workflow, provides a trustworthy experience for developers due to accurate model selection and cancellation, is portable to allow users to upgrade their systems when better tools come along, and is expandable towards integration with other Google Cloud services because the Gemini API it uses is part of that ecosystem.
