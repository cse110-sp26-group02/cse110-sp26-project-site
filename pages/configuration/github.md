# Overview

This page outlines steps for setting up GitHub - more specific than "QuickStart". 

# Guidance

Once you get on the "Configuration" page by clicking the rightmost icon in the top navigation menu of the extension...

1. Find the text input space that is labelled with "PAT" under the "Google Gemini" section.
2. Enter your GitHub PAT. You can click on the link provided at the bottom of the "GitHub" section to learn how to obtain it from your GitHub settings page.
3. Press the "Accept Changes" button at the end of the page. If nothing lights up in a "red" color, then you are authenticated.
